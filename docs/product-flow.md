# 阿留教育获客 H5 业务流程说明

更新时间：2026-09-23

## 1. 页面目标

通过三天家庭教育规划课程内容、完课资料和家长反馈完成课程转化，并收集后续学习服务所需的信息。

## 2. 报名流程

1. **下单确认**：展示课程名称、权益与应付金额 99 元。
2. **填写客户信息**：家长完成手机号、学校、学生和协议等必填信息。
3. **支付**：选择微信支付或支付宝；演示版仅模拟支付结果。
4. **添加微信**：支付成功后展示辅导老师二维码，引导家长扫码添加。

页面打开时不再请求手机号或微信授权。

## 3. 客户信息字段

| 字段 | 是否必填 | 规则 |
| --- | --- | --- |
| 家长手机号 | 是 | 中国大陆 11 位手机号，位于表单第一项 |
| 学校区域 | 是 | 省、市、区三级选择 |
| 学校名称 | 是 | 支持搜索选择或手动输入 |
| 是否住校 | 是 | 单选，默认“否” |
| 学生姓名 | 是 | 20 字以内的中文或英文 |
| 孩子年级 | 是 | 学龄前、小学、初中或高中 |
| 服务协议 | 是 | 提交信息前必须勾选 |

## 4. 支付成功处理

- 保存客户信息及来源参数。
- 模拟向家长预留手机号触发开课短信。
- 展示添加辅导老师微信页面。
- 家长添加后完成领取流程。

## 5. 当前页面内容

- 3 天课程安排：升学与兴趣规划、语文与英语规划、数理规划与连麦。
- 完课资料：语文、英语、数学和教育规划资源。
- 家长反馈：学科规划、时间管理、优势识别、升学路径及 AI 工具等主题。
- 主视觉仅保留体验价 99 元，不再展示划线原价和“一杯奶茶钱”文案。

## 6. 演示边界

当前版本为前端产品原型，支付、短信、客户数据提交和微信二维码均为模拟行为，不连接真实业务后台。
