# 阿留教育获客 H5 Demo

面向家长的三天家庭教育规划课程获客演示页。

## 在线预览

https://freya-pr.github.io/aliu-h5-demo/

## 当前业务流程

下单确认 → 填写客户信息 → 支付 → 添加班主任微信

当前版本已取消落地页微信授权，家长手机号改为信息表单第一项。支付成功后，页面模拟触发开课短信，并引导家长扫码添加辅导老师。

详细字段与交互规则见 [业务流程说明](docs/product-flow.md)。

## 演示说明

- 体验价为 99 元。
- 支付、短信和二维码均为产品原型演示，不会产生真实扣款、短信或微信添加行为。
- 学校支持列表选择、搜索和手动输入。
